# Jak wrzucić projekt do repo giveqq/revwlol

## Najprościej przez stronę GitHub

1. Wejdź w repo: `https://github.com/giveqq/revwlol`
2. Kliknij **Add file**.
3. Kliknij **Upload files**.
4. Przeciągnij całą zawartość folderu z tej paczki, nie sam folder.
5. Na dole wpisz commit message, np. `Add GIVERSS desktop app`.
6. Kliknij **Commit changes**.

Po wrzuceniu wejdź w **Actions** i odpal **Build Windows EXE**.

## Ważne

Nie wrzucaj do repo:

- Riot API key,
- tokenów GitHub,
- haseł,
- prywatnych plików konfiguracyjnych.

Aplikacja zapisuje ustawienia lokalnie na Twoim komputerze po uruchomieniu.
